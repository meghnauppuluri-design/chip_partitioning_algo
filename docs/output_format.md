# Program Output

## 1. Overview

The program produces two major categories of output:

1. console output
2. graphical output

The console output describes the FM partitioning process and final recursive
partition structure.

The graphical output represents the hierarchy using Graphviz.

## 2. Execution Messages

During execution, the program prints information associated with different
stages of FM partitioning.

These messages help show the progress of the algorithm.

The output includes information related to operations such as:

- partition initialization
- gain calculation
- gain buckets
- selected cells
- cell movement
- cut updates
- FM passes
- recursive partitioning

## 3. Final Partition Output

At the completion of recursive partitioning, the program prints a formatted
final-partition heading.

The final section follows the form:

```text
FINAL PARTITIONS
Partition: <recursive partition structure>
Best cut <cut value>
```

## 4. Recursive Partition Structure

The value printed after:

```text
Partition:
```

represents the recursive hierarchy generated by `fmRecursive()`.

Conceptually, a hierarchy such as:

```text
               Root
              /    \
             /      \
          Group A  Group B
           /  \      /  \
          0    1    2    3
```

is represented internally using the nested partition structure returned by
the recursive function.

## 5. Best Cut

The value printed after:

```text
Best cut
```

represents the cut information returned with the partition result.

During an FM pass, multiple cut values can be encountered.

For example:

```text
Initial cut : 15
After move 1: 12
After move 2:  9
After move 3: 11
```

The rollback operation restores the partition corresponding to the best cut
encountered during the pass.

## 6. Block Information in Graphical Output

Individual graphical block nodes contain:

```text
Block ID
Width × Height
Best Cut
```

For example:

```text
+----------------+
|       2        |
|      4x13      |
|   best_cut=... |
+----------------+
```

## 7. Partition Groups

Recursive groups are represented as Graphviz clusters.

Conceptually:

```text
+--------------------------------+
| Recursive Partition            |
|                                |
|  +-----------+ +-----------+   |
|  | Group A   | | Group B   |   |
|  +-----------+ +-----------+   |
|                                |
+--------------------------------+
```

Nested clusters show the hierarchy created by recursive FM partitioning.

## 8. Connectivity Edges

The graphical output also includes the original weighted connectivity
between blocks.

For example:

```text
Block 0 -------- 4 -------- Block 4
```

where:

```text
4
```

is the edge weight from the adjacency matrix.

## 9. Graphviz Output

The graph object generated by:

```text
drawBlocks()
```

is subsequently processed using the Graphviz operations present in the
program.

The program performs:

```text
view()
render()
save()
```

to display, render and save the graph.

## 10. Output Flow

```text
FM Recursive Partitioning
          |
          v
   Partition Structure
          |
          +--------------------+
          |                    |
          v                    v
   Console Output       Graphviz Output
          |                    |
          v                    v
Partition / Best Cut   Hierarchical Graph
```
